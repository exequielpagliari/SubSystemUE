\doxysubsection{Detailed Description}
Subsistema encargado de la gestión de configuraciones gráficas y rendimiento. 

Este subsistema actúa como una interfaz simplificada sobre UGame\+User\+Settings, permitiendo ajustar la resolución, niveles de escalabilidad y realizar benchmarks de hardware.
